# ✂️ Fama Barber - Landing Page

Hey there! 👋  
This is a clean and modern landing page I built for a fictional barbershop called **Fama Barber**. It's designed to be fast, responsive, and easy to customize — perfect for small businesses that need an online presence.

You can check out the live version here:  
👉 https://fama-barber-landing-alpha.vercel.app/

---

## 🚧 Why I Built This

I wanted to practice building a high-converting landing page using **Next.js** and **Tailwind CSS** — two tools I use a lot. This project focuses on clean layout, good performance, and a user-friendly experience across all devices.

---

## 🧰 Tech Stack

- **Next.js** – for routing and SSR
- **Tailwind CSS** – for utility-first styling
- **Framer Motion** – for smooth scroll-in animations
- **Vercel** – for quick deployment

---

## ⚙️ Features

- 💡 Hero section with a bold CTA
- 📋 Service section to showcase offerings
- 📱 Fully responsive (mobile-first)
- 🎯 Focused layout for conversions
- ⚡️ Deployed instantly with Vercel
